# 迦勒底终端 · FGO 羁绊配队助手

Windows 本机工具，用于从者与羁绊加成礼装条件匹配、固定队伍的礼装分配及收益估算。

## 下载与启动

[下载轻量启动包](https://github.com/Asairiina/fgo-bond-planner/releases/latest/download/fgo-bond-planner-lite.zip) · [版本与更新说明](https://github.com/Asairiina/fgo-bond-planner/releases/latest)

1. 完整解压到自己有写入权限的独立文件夹。
2. 双击 `启动助手.exe`。首次使用联网下载运行环境、应用程序及初始数据库，之后浏览器自动打开本机页面。
3. 首次初始化使用 Windows 系统代理；网络失败时重新启动可复用已经完成的组件。

仅支持 Windows x64，启动器依赖 Windows .NET Framework 4.5 或更高版本。无需另装 Python、登录 GitHub 或维护服务器。初始化后可以离线计算。

## 后续更新

- 启动时后台检查程序新版，也可点击“检查程序更新”。
- 发现新版本后点击“更新并重启”，自动下载、校验并切换；未确认不会自动安装。
- 程序、运行环境和初始数据分别发布，未变化的组件会复用。
- Wiki 数据通过“从 Wiki 更新数据”自行更新。个人库存、队伍配置与程序更新相互独立。
- 检查或下载失败可以继续使用已有版本；新版启动失败时启动器恢复旧版。
- 手动更新支持直连、系统代理和自定义 HTTP 代理。

## 卡面素材

在页面顶部点击“下载当前编队素材”“下载当前列表缩略图”或“下载全部配队素材”。图片来自 Mooncell，保存于 `user-data/art-cache`，下载后离线显示，不随程序更新重复下载。可停止下载，失败项可再次点击重试。未下载图片不影响配队计算。

## 旧版本迁移

先退出旧工具，将旧目录中的 `user-data` 文件夹复制到新版启动器旁边，再启动。也可以在旧版导出配置后，在新版导入。

个人数据不会上传至本仓库。迁移和备份时保留 `user-data`；移动安装位置时应移动整个文件夹。

## 数据来源与边界

资料来自 [Mooncell](https://fgo.wiki/)，初始数据库包含来源 URL、页面版本及时间。Wiki 非另行声明的内容遵循其 [CC BY-NC-SA](https://creativecommons.org/licenses/by-nc-sa/4.0/) 许可；游戏内容权利归原权利人。本工具与 Mooncell、游戏官方无隶属关系。

当前是理论收益模型，支持适用关卡的冠位报酬栏；不模拟战斗、活动加成或冠位星图，也不保证与游戏逐步取整完全相同。

此仓库用于发布安装组件、版本清单和说明，不维护开发源码。
